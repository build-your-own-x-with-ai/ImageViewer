# 需求文档

## 1. 项目目标

一个 Flutter 图像查看器，**六种格式的解码全部纯 Dart 手写**，用于教学：让读者从字节流一路读到屏幕上的像素，中间没有黑盒。

## 2. 核心约束

| 约束 | 说明 |
|---|---|
| 零第三方依赖 | 只用 Flutter SDK 自带的 `flutter` / `flutter_test`。不引入任何 pub.dev 包，连 `cupertino_icons`、`flutter_lints` 也不用。 |
| 零引擎解码 | 不调用 `ui.instantiateImageCodec` / `ui.decodeImageFromList` 解码图片。唯一允许的 `dart:ui` 图像调用是 `decodeImageFromPixels`，它只负责把我们算好的 RGBA 缓冲上传到 GPU，不参与任何解析。 |
| 可教学 | 代码结构对应格式规范的章节结构；关键算法（inflate、Huffman、IDCT、预测器）保留朴素实现或加详细注释；文档给出字节级剖析。 |
| 测试自包含 | `flutter test` 不依赖任何外部命令。样图一次性生成后提交进仓库。 |

## 3. 功能需求

### FR-1 格式支持

| 格式 | 必须支持的范围 |
|---|---|
| **BMP** | CORE / INFO / V4 / V5 头；1/4/8/16/24/32 bpp；调色板；RLE4 / RLE8；自底向上与自顶向下；`BI_BITFIELDS` 任意通道掩码 |
| **PNM** | P1–P6 全部六种；ASCII 与二进制；maxval 1–65535；注释与任意空白 |
| **YUV** | 裸流，尺寸与格式由用户指定。I420 / YV12 / NV12 / NV21 / YUY2 / UYVY / I422 / I444；BT.601 与 BT.709；limited / full range |
| **PNG** | 自写 inflate；五种 filter；色彩类型 0/2/3/4/6 × 位深 1/2/4/8/16；`tRNS`；Adam7 隔行 |
| **JPEG** | 基线与渐进式；任意采样因子（4:4:4 / 4:2:2 / 4:2:0 / 4:1:1）；重启间隔；YCbCr / 灰度 / Adobe CMYK-YCCK；EXIF 方向 |
| **WebP** | VP8L 无损（含四种变换、颜色缓存、meta-Huffman）；VP8 有损（布尔解码、帧内预测、环路滤波）；ALPH 透明通道 |

可选扩展（非必须）：APNG、WebP 动画（ANMF）。

### FR-2 格式识别

按魔数嗅探自动分发，不依赖文件扩展名。YUV 无魔数，作为显式回退。

### FR-3 查看器交互

- 缩放（滚轮 / 捏合 / 按钮）、平移拖拽、适配窗口 / 原始尺寸 / 填充
- 旋转 90° 与水平垂直翻转
- 透明区域用棋盘格背景显示
- 像素探针：悬停显示坐标与该点 RGBA 值
- 格式信息面板：尺寸、位深、色彩类型、压缩方式、解码耗时等格式相关元数据

### FR-4 文件来源（分平台）

不用第三方库时各平台能力不同，这是明确接受的取舍：

| 平台 | 能力 |
|---|---|
| macOS / Windows / Linux | 自写目录浏览侧栏（`dart:io`）+ 命令行传入路径，可打开任意本地文件 |
| iOS / Android | 内置 assets 样图 + 应用沙盒目录 |
| Web | 仅内置 assets 样图 |

六个平台都必须能编译通过并运行，通过条件导入隔离 `dart:io`。

### FR-5 教学模式

分步可视化解码中间产物：

- PNG：各 filter 阶段前后对比
- JPEG：单个 8×8 块的 DCT 系数矩阵、量化表热图
- WebP：预测器模式分布图
- YUV：Y / U / V 三平面分离显示

### FR-6 错误处理

畸形输入必须抛出带明确信息的异常（而非崩溃或静默产出错图），并在 UI 上友好呈现。截断、尺寸溢出、CRC 不匹配、未知 marker 等都要覆盖。

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 解码在 `Isolate.run` 中进行，不阻塞 UI（Web 无 isolate，内联回退）。1080p PNG 解码目标 < 1s。 |
| 健壮性 | 所有读取越界检查，不信任文件里声明的任何长度字段。 |
| 可测试性 | 解码器为纯函数：`Uint8List → RgbaImage`，不碰 IO 与 UI，可直接单测。 |
| 代码质量 | `flutter analyze` 零告警。 |
| 可访问性 | 交互控件有语义标签，键盘可操作。 |

## 5. 验收标准

1. 六种格式各自的测试用例全部通过，覆盖正常图与畸形输入
2. 解码结果与参考实现（系统 codec 转出的 PPM）逐像素比对通过（JPEG 允许 ±2 通道容差）
3. `flutter analyze` 零告警，`flutter test` 全绿
4. 六平台均可构建
5. 文档完整：需求、设计、计划、实现记录、测试说明、六份格式剖析

## 6. 不在范围内

编码/保存、图像编辑、批量处理、色彩管理（ICC）、EXIF 完整解析（只取方向）、GIF / TIFF / HEIF / AVIF。
